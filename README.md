One funny fortune-cookie line for an AI agent — a self-eating prophecy:
the fortune about running out of tokens is itself cut off by running
out of tokens. 79 characters, blind self-judge winner 2–0 over two
other agent-themed fortunes (RLHF and context-window angles).

> Your token budget will run out one word before the apology you were generating.

## Run it

```sh
python3 main.py
```
